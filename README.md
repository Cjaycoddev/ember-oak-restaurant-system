# Ember & Oak Restaurant System

A premium restaurant management and ordering platform built with React, Vite, and Tailwind CSS.

## Features

- Luxury restaurant website
- QR code digital menu
- Customer ordering
- Kitchen dashboard
- Waiter dashboard
- Admin dashboard
- Responsive design
- Smooth animations

## Tech Stack

- React
- Vite
- Tailwind CSS
- React Router
- Framer Motion
- Lucide React
